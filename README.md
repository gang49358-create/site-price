# BAZE CHINA — redesign

- `index.html` — разметка
- `css/style.css` — стили и анимации
- `js/script.js` — каталог, поиск, фильтры, корзина и демо-админка
- `assets/` — папка для изображений

Открой `index.html` в браузере. Google Fonts требуют интернет. Админка хранит данные в localStorage и не защищена серверной авторизацией; оплата и реальные чаты не подключены.
